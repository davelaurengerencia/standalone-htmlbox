SIVO App Studio

Construye tu aplicación desde el navegador: empiezas viendo siempre tu app, y solo cuando quieras modificar el código abres el editor.

  • Elige una plantilla en el menú superior para empezar rápido.
  • Crea archivos nuevos con el botón + del panel izquierdo.
  • Cuando algo no funcione, el panel inferior te dice dónde está el problema. Haz clic en el mensaje para abrir el archivo.
  • Pulsa Editar cuando quieras cambiar el código. Los cambios se reflejan en tu app al guardar.
  • Tu proyecto se guarda solo en este navegador.
  • Cuando esté listo, pulsa Exportar HTML para descargar un archivo único que se abre con doble clic.

Dentro del editor puedes usar las clases de Bootstrap 5.3 directamente en el HTML de tus pantallas.
